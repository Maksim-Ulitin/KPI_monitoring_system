# Система мониторинга KPI
## Запуск (macOS, VS Code)
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run main.py
```

В браузере откроется локальная страница приложения
Данные сохраняются в `kpi.sqlite3` рядом с файлами проекта (создаётся автоматически).

## Пример «Доля оплат через СБП»

1. На вкладке **Импорт CSV** загрузите `examples/payments.csv` и сохраните его.
2. Перейдите в **Создание KPI**, задайте название «Доля СБП по сумме» и выберите загруженный набор.
3. Выберите `date` как дату, **Процент / доля** как тип расчёта, **Сумме значений** как базу процента.
4. Выберите `amount` как числовой столбец, `payment_method` как столбец фильтра и `SBP` как значение.
5. Единица `%`, план `35`. Создайте KPI и откройте вкладку **Мониторинг**.

Появятся данные по месяцам. Доля СБП вычисляется как **сумма оплат со способом SBP / сумма всех оплат × 100** за каждый месяц. Для января — 40% (40 000 / 100 000), отклонение от плана +5 процентных пунктов.

## Ограничения этой версии

- CSV с заголовками, разделителями `,` или `;`, кодировкой UTF-8/Windows-1251; до 5 МБ / 25 000 строк.
- Даты (предпочтительно `YYYY-MM-DD`); месячная группировка.
- Четыре операции: **сумма, количество строк, среднее, процент**. Процент — по числу записей либо по сумме выбранного числового поля, с одним условием равенства.
- Числа с десятичной точкой или запятой; для разрядов допускаются пробелы. Не используйте формат `1,234.56` (английские разделители тысяч).
- План один для всех месяцев каждого KPI; его можно изменить.
- Загруженные данные сохраняются в SQLite, повторный импорт **точно того же файла** распознаётся по SHA-256. Изменённый файл считается **новым набором данных**, автоматическое слияние и обновление существующего набора не реализованы.
- Нет автоматической синхронизации внешних источников, проверки бизнес-смысла колонок, прогнозов или произвольных пользовательских формул.
- Для процентного расчёта по сумме исходные значения предполагаются неотрицательными и выраженными в одной единице. Для доли по количеству каждая строка соответствует одной операции.
- В демонстрационных графиках показаны **факт, план и отклонение**, без оценки «хорошо/плохо».

## Файлы

- `main.py` — три вкладки интерфейса и точка входа Streamlit
- `database.py` — сохранение импортов и параметров KPI в SQLite
- `csv_import.py` — чтение и проверка CSV
- `calculations.py` — расчёты и группировка по месяцам
- `tests/test_core.py` — автоматические проверки расчётов и импорта
